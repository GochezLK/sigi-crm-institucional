# SIGI CRM Institucional

Frontend inicial basado en el maquetado `SIGI - CRM Institucional.pdf`.

## Ejecutar

```powershell
python -m http.server 4173
```

Abrir `http://127.0.0.1:4173`.

La persistencia real de organizaciones, personas, solicitudes y proyectos requiere una API y base de datos propia. ntfy se usará como canal de notificaciones.
